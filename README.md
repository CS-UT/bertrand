# پارادوکس برتراند

شبیه‌سازی تعاملی و فارسیِ پارادوکس برتراند برای مقایسهٔ سه روش انتخاب وتر تصادفی.

## توسعهٔ محلی

```bash
npm install
npm run dev
```

برای بررسی نسخهٔ production:

```bash
npm run build
npm run preview
```

با تغییر مقدار `N`، نمونه‌گیری دوباره انجام می‌شود. برای خوانایی، حداکثر ۱۰۰۰ وتر در نمودارها رسم می‌شود، اما محاسبات آماری روی کل نمونه انجام می‌گیرد.

## ساختار

- `src/main.js` منطق شبیه‌سازی، رسم نمودارها و رندر فرمول‌ها را نگه می‌دارد.
- `src/styles.css` استایل صفحهٔ RTL را جدا می‌کند.
- `public/` فونت Vazirmatn، لوگوها و favicon را برای استفادهٔ مستقیم در خروجی Vite نگه می‌دارد.
- `vercel.json` تنظیمات build و هدرهای پایهٔ امنیتی را تعریف می‌کند.

## استقرار
